## Vault (zaednicka memorija na GoDevLab)

Vault-ot (Obsidian, posebno git repo) e na `../../Vault`, t.e. `GoDevLab/Vault`. Ovoj proekt vo nego e `Proekti/GoDevLab Hub/`.

- **Pred zadaca:** procitaj `../../Vault/Proekti/GoDevLab Hub/Status.md` i `GoDevLab Hub Pregled.md` (ako postoi).
- **Po zavrsena zadaca ili vazna odluka** (ne po sekoja poraka): dopishi kratok zapis vo `../../Vault/Dnevnik/YYYY-MM-DD-<ime-na-covek>.md` (proekt, sto e napraveno, odluki, sleden cekor), azuriraj go `Status.md` samo ako se smenila sostojbata, pa vo `../../Vault` napravi `git pull`, commit `vault: <kratko>` i `git push`.
- Ne pisuvaj lozinki, API klucevi ni tokeni vo vault-ot. Povekje detali: `../../Vault/CLAUDE.md`.
